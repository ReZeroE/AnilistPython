## Quick Setup
To setup `AnilistPython`, install directly from [PyPI](https://pypi.org/project/AnilistPython/) using pip:
```python
pip install AnilistPython==1.0.0
```
OR
```shell
git clone https://github.com/ReZeroE/AnilistPython.git
cd AnilistPython/
pip install setuptools
pip install -e .
```
